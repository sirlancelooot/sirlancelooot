## 🧠 Engineering Philosophy

> Build software that is easy to understand, test, change, and operate.

I value:

**Practical architecture**
Choose the appropriate level of complexity for the problem instead of over-engineering.

**Maintainability**
Code should be understandable by the next developer who works on it.

**Quality through collaboration**
Code reviews, testing, automation, and shared standards are team responsibilities.

**Continuous improvement**
Technical practices should evolve as the team, product, and technology change.

**People over process**
Processes should help developers deliver better software, not become an obstacle to delivery.
